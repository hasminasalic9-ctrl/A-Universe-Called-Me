
# A Universe Called Me

*Every thought, every dream, every little piece of me.*

Welcome to my personal digital universe.

A space where I can express myself, preserve memories, write diaries, share creativity, document discoveries, and explore my dreams.

## About This Project

A Universe Called Me is a personal digital space inspired by creativity, self-expression, memories, emotions, technology, and the beauty of the universe.

## Features

- Day Sky and Night Universe themes
- Personal reflections and creative writing
- Dreams and destinations
- A little library of feelings
- Creative experiments and discoveries
- Personal milestones and memories

## Design Philosophy

A combination of celestial aesthetics, minimalist design, and scrapbook-inspired elements.

**Color palette:** Sky blue, deep blue, midnight navy, white, black, and subtle gold.

## Technology

- HTML
- CSS
- JavaScript
- GitHub Pages
- Supabase (planned for future private features)

## Development Status

Currently in Phase 1: Foundation.

More pieces of this universe will be added as the project grows.
